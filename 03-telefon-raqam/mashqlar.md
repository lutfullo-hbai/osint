# 3-modul: Mashqlar

## Mashq 1: Kutubxonani o'rnatish ⭐
```bash
pip install phonenumbers
```

## Mashq 2: Skriptni ishga tushirish 🎯 (KOD!)
```bash
python3 03-telefon-raqam/kod/phone_info.py +998901234567
```
O'z raqamingiz bilan sinang! Savollar:
1. Operatoringiz to'g'ri chiqdimi?
2. `is_valid_number` natijasi nima bo'ldi?

## Mashq 3: Yolg'on raqamlarni toping ⭐⭐
Quyidagi raqamlarni skriptga bering va farqini ayting:
```
+998991234567   (bunday operator kodi yo'q)
+79012345678    (Rossiya raqami)
+12345678901    (AQSh)
```

## Mashq 4: Telegram tekshiruvi ⭐
Brauzerda oching:
```
https://t.me/+998901234567
```
- Profil chiqdimi? → raqam Telegramda band
- "User not found"? → band emas yoki maxfiylik sozlamalari

## Mashq 5: Skriptni kengaytirish 🎯⭐⭐ (KOD!)
[phone_info.py](kod/phone_info.py) ga quyidagini qo'shing:
- [ ] Bir vaqtda fayldan ko'p raqam o'qish (`numbers.txt`)
- [ ] Natijalarni CSV faylga saqlash
- [ ] O'zbekiston operatorlari ro'yxati (kod → operator): 90, 91 = Beeline; 93, 94 = Ucell; 97 = Mobiuz; 99 = Uzmobile... to'liq jadval yarating

## Mashq 6: Qo'lda kompleks tadqiqot 🎯
Biror jamoat raqamini tanlang (masalan, OLX e'lonidagi):
1. Skript bilan asosiy ma'lumot oling
2. Google'da turli formatlarda qidiring
3. Telegram + WhatsApp + Viber'da borligini tekshiring
4. Topilganlarni hisobot qilib yozing (razvedka tsikli!)
