# 2-modul: Mashqlar

## Mashq 1: whatsmyname.app da o'zingizni tekshiring ⭐
1. https://whatsmyname.app saytiga kiring
2. O'z username'ingizni kiriting
3. Nechta saytda topildi?

## Mashq 2: Sherlock o'rnatish va ishga tushirish ⭐⭐
```bash
pip install sherlock-project
sherlock --timeout 10 target_username
```
Natijani `fayl`ga saqlang:
```bash
sherlock target_username -o natija.txt
```

## Mashq 3: O'z skriptingizni yozing 🎯 (KOD!)
[kod/username_checker.py](kod/username_checker.py) ni yuklab, ishga tushiring:
```bash
python3 kod/username_checker.py istalgan_username
```

Keyin vazifa — skriptni kengaytiring:
- [ ] Yangi sayt qo'shing (masalan, github.com/{username})
- [ ] Natijalarni `.txt` faylga saqlash funksiyasi qo'shing
- [ ] Bir nechta usernameni birdan tekshirish imkonini qo'shing
