## ⚠️ Etika va qonun (birinchi qoida!)
- Faqat **ochiq, jamoat manbalaridan** foydalaning
- Odamlarga **zarar bermang**, shaxsiy hayotni buzilmang
- O'zbekiston RK va xalqaro qonunlarga rioya qiling
- Maqsad: himoya, tadqiqot, jurnalistika — emas: doxxing, tahdid
